# RAG(检索增强生成)概述

## 什么是 RAG

RAG(Retrieval-Augmented Generation,检索增强生成)是一种将信息检索与大语言模型生成相结合的技术。它先从外部知识库中检索与问题相关的文档片段,再将这些片段作为上下文提供给大语言模型,从而生成有事实依据的回答。

## RAG 的优势

RAG 相比传统大语言模型主要有以下优势:

1. 减少幻觉:回答基于检索到的真实文档,而不是模型的记忆,降低编造事实的概率。
2. 知识可更新:只需更新知识库即可让模型获得新知识,无需重新训练模型。
3. 可溯源:每个回答都可以附带来源引用,便于核查与信任。
4. 成本更低:相比微调大模型,构建知识库并检索的成本更低。

## RAG 的完整链路

一个完整的 RAG 系统包含如下阶段:文档加载(Loader)、文本切分(Splitter)、向量化(Embedding)、向量数据库存储(Vector Database)、检索(Retriever)、重排序(Reranker)、上下文压缩(Context Compression)、提示构建(Prompt)、大模型生成(LLM),最终得到带来源的答案。

## Rerank 重排序的作用

向量检索通常召回 Top 20 个候选片段,但相似度检索并不总是把最相关的片段排在最前面。Rerank 使用 Cross-Encoder 对(查询,文档)对进行精细打分,从 20 个候选中选出最相关的 Top 5 作为最终上下文,从而显著提升上下文质量与回答准确率。
