# LangGraph 与 Agent 工作流

## 什么是 LangGraph

LangGraph 是一个用于构建有状态、多步骤大语言模型应用的框架。与简单的 Chain 不同,LangGraph 用图(Graph)来编排流程,支持循环、条件分支与显式状态管理,非常适合构建自主 Agent。

## LangGraph 的核心概念

LangGraph 有四个核心概念:

1. State(状态):在整个图执行过程中传递和更新的共享数据结构。
2. Node(节点):对状态进行读写的函数,每个节点完成一个具体步骤。
3. Edge(边):连接节点,定义执行顺序。
4. Conditional Routing(条件路由):根据状态动态决定下一个执行的节点。

## Agent 工作流

本平台的 Agent 工作流为:入口 START,首先经过意图路由(Intent Router)判断问题是否需要知识库或工具;随后进入条件分支,或走 RAG 节点(检索、重排序、生成),或走工具节点(Tool);生成之后经过自我校验(Self Critique)节点检查是否有事实依据、是否回答了问题、是否产生幻觉;若校验失败则重新生成,通过则结束 END。

## Tool Calling 与普通函数的区别

普通函数由程序在编写时固定调用,参数由开发者传入。Tool Calling 则由大语言模型根据语义自主选择要调用的工具,并自动生成调用参数,Agent 会动态规划整个调用流程。这使得系统能够根据用户意图灵活地使用计算器、搜索、文件查询等不同工具。
